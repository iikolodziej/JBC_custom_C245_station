# Enclosure

SolidWorks model of the station case.

<p align="center"><img src="../docs/images/enclosure_render.png" width="60%" alt="Enclosure render"></p>

| File | Contents |
|---|---|
| `Złożenie1.SLDASM` | assembly of the whole case (*złożenie* = assembly) |
| `Część1.SLDPRT` … `Część4.SLDPRT` | case parts (*część* = part) |
| `Część3.STL`, `Część4.STL` | parts 3 and 4 ready for 3D printing |
| `IEC Power Socket.SLDPRT` | mains socket model used in the assembly |
| `nextion2.8/` | manufacturer 3D model of the Nextion NX3224T028 display (STEP) |

STL files for parts 1 and 2 can be exported from SolidWorks (`File → Save As → STL`).

Do not rename the part files: the assembly refers to them by name.
